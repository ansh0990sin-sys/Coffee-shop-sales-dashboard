# COFFEE SHOP Sales Dashboard

## Project Overview
An interactive Power BI dashboard created to analyze COFFEE SHOP sales data.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV

## Dashboard Features
- Total Sales
- Total Orders
- Sales by Region
- Sales by Category
- Sales by State
- Sales Trends
- Regional Analysis
